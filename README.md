# ST10534569-Web-Dev-Part-2
Stylesheet linking and baseline fixes were done by adding a link that joins the external css stylesheet to the "head" tag of all the HTML files so the external stylesheet renders across every page. 
Design and color Scheme I added a deep navy primary theme with gold accents, soft card backgrounds, rounded corners (border-radius), subtle box shadows, and updated Google Typography (Outfit and Plus Jakarta Sans).  
For the layout I restructured the main page elements using CSS Grid and Flexbox to enforce consistent maximum content widths and centered page alignment across all device viewports. 
Interactive hover states are upgrades done to the list cards (including the Home, Services and Leadership sections) with CSS hover transitions that lift elements, brighten borders, and shift background tones when hovered.
Updated the feature list layout and imagery of the homepage by adding new information and image (Why is the channel important?) list items to use a side-by-side flexbox layout, placing larger square images on the right side of the text content.
Form styling I added new style form inputs, textareas, radio buttons, and submit buttons with clean borders, focus outlines, and dark hover states for better user accessibility. 
Responsive base and viewport configurations are integrated in the viewport tag and fluid media query breakpoints to scale text sizes, margins, images, and card grids down for tablet and mobile devices. 
Recent changes were made to project. JavaScript has been implemented to improve the websites overall performance and functionality. The features that are implemented in this website are dynamic content and search/sort to the service webpage followed by  accordions in the same webpage with the function of clicking to expand or collapse the descriptions. A lightbox gallery is also added to the "index.html" so that when users click the feature images they open in a large overlay. Then scroll transitions will  allow elements to fade and slide in as the user scrolls down the page. The website has Meta Descriptions and Keywords that help with SEO. A new files were also added "robots.txt" and  "sitemap.xml" they tell the search engines they are allow to crawl the website and to map out the structure of the website for google. The JS that was added also change to forms functionality for the contact form and enquiry form to add client-side validation, error handling, AJAX Simulation and the specific dynamic responses required for each form.
